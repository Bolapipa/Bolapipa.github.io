# bolapipa.github.io

Portfólio de **Arthur Viana Delacorte**, Engenheiro de Dados (Azure Databricks · PySpark · SQL · Python · Delta Lake).

Site estático em HTML, CSS e JavaScript puros, sem etapa de build, publicado na Vercel em https://arthurdelacorte.vercel.app.

## Estrutura

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Seções: início com terminal interativo, sobre, projetos, stack, experiência e contato |
| `style.css` | Identidade visual (azul-noite, ciano e cores das camadas Medallion) |
| `main.js` | Menu, animações de entrada, contadores, formulário (mailto) e comandos do terminal |
| `assets/CV_Arthur_Delacorte.pdf` | Currículo para download |

## Rodar localmente

Abra o `index.html` no navegador.

## Atualizar o CV

Substitua `assets/CV_Arthur_Delacorte.pdf` mantendo o mesmo nome.
